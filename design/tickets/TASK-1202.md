## 1. 任务背景与目标

系统直连 DeepSeek-V3、Claude 3.5 Sonnet 与 OpenAI API，支持一键批量补翻多语种。  
若用户误点高并发请求或遭受恶意脚本轮询刷取，极易导致昂贵外部 API 资费超支或服务雪崩。  
本任务旨在引入**双层限流与额度熔断安全保护**：
1. **基础 API 频次限制**：普通查询与修改接口限制单 IP / 单用户 600 req/min，防爬虫与异常循环调用。
2. **AI 网关预算守卫**：限制单用户单次批量翻译最多 200 条；当单日消耗达到团队设定的预警阈值时，自动平滑切换至本地免资费模型（如 Ollama / 本地缓存 TM）。

---

## 2. 详细功能规格与实现要求

1. **Fastify Rate Limit 集成**：
   - 区分不同路由组：
     - 普通业务接口：最大 600 次/分钟。
     - AI 直连补翻接口：最大 30 次/分钟。
   - 触发限流时返回 `429 Too Many Requests`，并在响应头携带 `Retry-After`。
2. **预算守卫熔断器**：
   - 在内存/Redis 中维护日累计 Token 使用量，超过 $50/日 预算时，邮件预警并提示需系统管理员确认继续放行。

---

## 3. 验收标准 (Acceptance Criteria)

- [ ] 高频请求 AI 批量翻译超过限额阈值时，客户端收到可读的冷却提示，无法继续向外部供应商发起计费请求。
- [ ] 正常单条人工翻译与常规大表浏览不受任何负面拦截影响。
