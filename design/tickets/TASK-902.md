## 3. 技术契约与详细设计 (Technical Specification)

### 3.1 灰度切流三阶段
1. **阶段 1：影子运行 (Shadowing)**：10% 流量双写，比对两端结果一致性；
2. **阶段 2：单项目试运行**：迈金 C606 试点切流至新系统进行实际发版作业；
3. **阶段 3：全量割接**：DNS / 网关全量流量切换至 Fastify 新单体服务。

### 3.2 应急回滚关键路径 (3 分钟 SLA)
```
[发现不可逆严重故障]
         ↓ (10s)
1. 切换网关/DNS 流量重定向至老 Express 服务
         ↓ (30s)
2. 老服务通过 PostgreSQL 兼容视图 `view_terms_legacy` 直接读取新系统已落库的数据
         ↓ (60s)
3. 验证老服务读写接口正常，通知业务恢复
[回滚完成: 总耗时 < 180s, 数据 0 丢失]
```
