## 1. 任务背景与目标

在大数据量大网格场景下，译员在多语言网格中直接打字修改是最高频操作。为了达到极致流畅体验，前端输入必须满足：
1. **打字零等待**：输入后立即在本地 UI 响应并标记“保存中...”（乐观更新）。
2. **防抖与自动提交**：用户停顿输入 1.5 秒后，自动打包向后端提交；或按 `Enter`/失焦时立即提交。
3. **失败回滚**：若后端返回并发冲突或网络异常，自动撤回修改并提示红色错误气泡。
4. **实时审计联动**：保存成功后，审计流水页与历史抽屉自动无感刷新最新变更记录。

## 2. 详细功能规格与实现要求

### 2.1 React Query 乐观更新实现
```typescript
useMutation({
  mutationFn: ({ termId, lang, text }) => updateTermTranslation(termId, lang, text),
  onMutate: async (newTranslation) => {
    // 1. 取消正在执行的 queries
    await queryClient.cancelQueries({ queryKey: ['terms'] });
    // 2. 保存旧快照
    const previousTerms = queryClient.getQueryData(['terms']);
    // 3. 乐观写入本地缓存
    queryClient.setQueryData(['terms'], (old) => updateLocalTerm(old, newTranslation));
    return { previousTerms };
  },
  onError: (err, newTranslation, context) => {
    // 失败时精准回滚到 previousTerms
    if (context?.previousTerms) {
      queryClient.setQueryData(['terms'], context.previousTerms);
    }
    toast.error('保存失败: ' + err.message);
  },
  onSettled: () => {
    // 触发局部失效刷新，并同步刷新审计日志缓存
    queryClient.invalidateQueries({ queryKey: ['audit-logs'] });
  }
});
```
