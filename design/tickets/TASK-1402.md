## 1. 任务背景与目标

新环境（无论是 staging 测试服还是企业内网私有化部署）初次启动时，数据库通常为空。运营人员或固件团队需要花费大量时间重新录入基础产品线和基础词条。  
本任务旨在打造一键化**开箱即用冷启动种子数据管道 (`npm run db:seed`)**：
1. **真实硬件业务数据资产**：内置迈金科技代表性产品线（C606 智能码表、C706 高端码表、T300 智能骑行台、OnelapFit 移动 App）及其真实基线版本。
2. **官方核心术语与 TM 记忆库预热**：内置 500+ 条经过审核的标准硬件传感器术语（心率、踏频、功率、阻力、坡度、雷达告警），直接预热 pgvector 向量空间。
3. **幂等性保障**：脚本重复执行时自动跳过已存在记录，绝不破坏现有生产数据。

---

## 2. 详细功能规格与实现要求

```bash
# 执行方式：
npm run db:seed
# 或在 Docker Compose 启动时受控参数触发：
# SEED_DATABASE_ON_STARTUP=true
```

---

## 3. 验收标准 (Acceptance Criteria)

- [ ] 在全新空白 PostgreSQL 数据库上运行 `npm run db:seed`，能在 5 秒内注入完成全套产品线、基线版本与 500+ 条完整词库。
- [ ] 再次运行该脚本，终端提示“已存在，跳过注入”，数据总量不变。
