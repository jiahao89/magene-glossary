## 1. 任务背景与目标

在智能骑行码表（如迈金 C606、C706）本地化过程中，译员脱离真实硬件界面直接翻译，经常不知道词条是显示在“顶部状态栏”、“HUD 抬头导航区”还是“底部弹窗提示”。  
目前 TASK-703 已经实现了基础的点阵屏幕拟真，本任务进一步实现**真机实拍照/设计稿热区联动映射**：
1. **词条-热区双向聚焦**：在 CAT 工作台选中某一词条时，真机视窗自动高亮对应的 UI 区域；点击图片上某热区框，自动选中对应词条。
2. **直观交互圈选**：支持产品经理/UI 设计师在网页上直接拖拽鼠标圈选屏幕区域，保存归一化坐标 `[x, y, width, height]`（0.0 ~ 1.0）。

---

## 2. 详细功能规格与实现要求

### 2.1 归一化坐标模型
```typescript
export interface TermUiHotspot {
  id: string;
  termId: string;
  screenImageId: string;
  // 归一化百分比坐标 (自适应任意分辨率设备与缩放)
  bbox: {
    x: number;      // 0.0 ~ 1.0 (left)
    y: number;      // 0.0 ~ 1.0 (top)
    width: number;  // 0.0 ~ 1.0
    height: number; // 0.0 ~ 1.0
  };
  uiContext: 'status_bar' | 'dialog' | 'hud_metric' | 'settings_item';
}
```

### 2.2 视觉高亮渲染
- 使用 SVG `<rect>` 叠加在真实真机截图上方。
- 激活词条的热区带呼吸流光动效（`animate-pulse`），并弹出微型气泡提示当前语种译文。
