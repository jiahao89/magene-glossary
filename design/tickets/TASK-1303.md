## 1. 任务背景与目标

生产运行需要具备高可用与可观测性保障。本任务旨在：
1. **就绪与存活探针 (Liveness & Readiness Probes)**：
   - `/health/liveness`：服务进程存活响应。
   - `/health/readiness`：深度探测 PostgreSQL 16 数据库连接池与 pgvector 插件状态。
2. **Nginx 反向代理与动静态分离**：
   - 配置前端静态资源长期客户端缓存（`Cache-Control: public, max-age=31536000, immutable`）。
   - 开启 Brotli / Gzip 极速文本压缩，大幅降低首屏 CSS / JS 静态资源载入耗时。
   - 转发 `/api/` 路由到后端 Fastify 端口，配置超时与连接复用。

---

## 2. 详细功能规格与实现要求

```nginx
# docker/nginx/nginx.conf 核心配置片段
server {
    listen 80;
    server_name _;

    # 前端构建静态产物
    location / {
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;
        gzip_static on;
    }

    # 后端 REST API 反代
    location /api/ {
        proxy_pass http://glossa-server:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```
