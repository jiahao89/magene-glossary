## 1. 任务背景与目标

目前系统支持浅色（Light）与深色（Dark）双主题无缝切换，大网格亦支持多语言列显隐切换。但在用户刷新页面或重新打开浏览器标签页时，设置会重置为默认值。  
本任务旨在实现用户本地偏好的无感持久化存储：
1. **主题偏好记忆**：记住用户选择的 `light` 或 `dark` 模式，首屏加载时在 DOM 渲染前应用，杜绝白屏闪烁（FOUC）。
2. **矩阵语言列视图记忆**：不同岗位的译员关注不同语种（例如德语译员只关注 de/en），记住每个用户勾选的可见语言列。
3. **工作台折叠状态记忆**：记住左侧产品导航树与 CAT 工作台侧栏的展开/折叠偏好。

## 2. 详细功能规格与实现要求

```typescript
export interface UserPreferencesState {
  theme: 'dark' | 'light';
  visibleLanguages: string[];
  activeProjectId: string;
  isSidebarCollapsed: boolean;
  setTheme: (theme: 'dark' | 'light') => void;
  setVisibleLanguages: (langs: string[]) => void;
  // ...
}

export const useUserPreferencesStore = create<UserPreferencesState>()(
  persist(
    (set) => ({
      theme: 'dark',
      visibleLanguages: ['en', 'de', 'fr', 'es'],
      activeProjectId: 'proj-c606',
      isSidebarCollapsed: false,
      setTheme: (theme) => {
        document.documentElement.classList.remove('dark', 'light');
        document.documentElement.classList.add(theme);
        set({ theme });
      },
      // ...
    }),
    { name: 'glossa_user_preferences_v2' }
  )
);
```
