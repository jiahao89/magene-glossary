## 1. 任务背景与目标

虽然目前已有 Milestone 1~5 的契约及脚本级测试网，但用户界面交互的真实浏览器渲染、键盘快捷键事件传递、深浅主题切换仍需通过真机浏览器自动化保障：
1. **真实浏览器端到端覆盖**：针对 Chromium、Firefox、WebKit 浏览器引擎进行自动化测试。
2. **核心业务心流校验**：
   - 用户打开大表，双击单元格输入文字，按 Enter，验证变更保存成功。
   - 打开 CAT 工作台，按 `Alt+1` 采纳 TM，按 `Ctrl+Enter` 自动保存并步进下一条。
   - 打开版本 Diff 页面，勾选 1 条变更项点击合并，再进入审计页面点击“时光机回退”，验证后悔药安全回退机制工作正常。

## 2. 详细测试场景覆盖要求

```typescript
test('CAT Studio: Ctrl+Enter 保存并自动流转至下一条词条', async ({ page }) => {
  await page.goto('/#cat');
  // 检查专注词条初始状态
  await expect(page.locator('[data-testid="cat-studio-three-pane"]')).toBeVisible();
  // 模拟输入
  await page.locator('textarea').fill('Test new translation');
  // 触发快捷键 Ctrl+Enter
  await page.keyboard.press('Control+Enter');
  // 验证保存状态与焦点自动切换至下一个词条
});
```
