# Triage Labels

This repository uses the canonical five-role triage vocabulary for tasks, bugs, and refactoring items:

| Label | Role & Purpose |
|-------|----------------|
| `needs-triage` | Newly filed item; requires investigation, scope verification, and triage. |
| `needs-info` | Blocked on missing requirements, ambiguous design, or user clarification. |
| `ready-for-agent` | Fully specified, actionable task ready for an AI agent to implement autonomously. |
| `ready-for-human` | Requires manual user intervention (e.g., credentials, business decisions, hardware QA). |
| `wontfix` | Deemed out of scope, superseded, or rejected after technical analysis. |
